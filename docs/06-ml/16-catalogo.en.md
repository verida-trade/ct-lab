# ML Component Catalog

> `ct://ml/catalog` — live catalog of all ML pipeline components.

**Resource:** `ct://ml/catalog`

Always consult the catalog instead of relying on hardcoded lists — new components may be added.

### How to query

**Chat:**
> List available ML components

The model reads `ct://ml/catalog` and returns the complete list with types, parameters and descriptions.
