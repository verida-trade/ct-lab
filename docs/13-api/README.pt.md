# API REST do CT Lab

> Controle programático do CT Lab via HTTP — chat, agentes, receitas, scheduler e tunnel.

O **CT Lab Desktop** roda internamente um servidor HTTP (`ct-labd`) na porta local
8420 (configurável). Este servidor expõe uma API REST que permite acionar receitas,
gerenciar agentes, agendar jobs e enviar mensagens de chat — tudo programaticamente,
a partir de aplicações externas.
