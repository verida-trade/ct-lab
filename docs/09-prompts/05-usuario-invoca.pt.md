# Invocação B — Usuário-Invoca (UI)

> O usuário seleciona um prompt na UI → form de argumentos → `prompts/get` injeta no chat.

No CT Lab Desktop, o usuário pode:

1. Abrir a lista de prompts (Settings ou paleta)
2. Ver os argumentos esperados (schema + completions)
3. Preencher e clicar "Usar"
4. `prompts/get` injeta as mensagens no chat
5. O modelo executa o workflow

> Variante leve: botão **"Usar"** na lista de Settings que já existe.

Esta é a UX por cima do piso (Opção A). Ambas compõem — A é o piso, B é conveniência visual.
