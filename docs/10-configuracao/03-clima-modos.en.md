# CT Lab Modes (Auto vs Chat)

CT Lab has two operation modes:

| Mode | Description | When to use |
|---|---|---|
| `auto` | Agent decides when and which tools to call | Natural flow, hands-off |
| `chat` | Agent asks before each action | Full control, debugging |

Configure via env: `CT_MODE=auto` or `CT_MODE=chat`

> See [Installation — AI Provider](../01-instalacao/02-provider-ia.en.md) for provider configuration details.
