# Invocation B — User-Invoked (UI)

> The user selects a prompt in the UI → argument form → `prompts/get` injects into chat.

In CT Lab Desktop, the user can:

1. Open the prompt list (Settings or palette)
2. See expected arguments (schema + completions)
3. Fill in and click "Use"
4. `prompts/get` injects the messages into chat
5. The model executes the workflow

> Light variant: **"Use"** button in the existing Settings list.

This is the UX on top of the floor (Option A). Both compose — A is the floor, B is visual convenience.
