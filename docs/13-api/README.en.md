# CT Lab REST API

> Programmatic control of CT Lab over HTTP — chat, agents, recipes, scheduler and tunnel.

The **CT Lab Desktop** internally runs an HTTP server (`ct-labd`) on local port 8420
(configurable). This server exposes a REST API that lets you trigger recipes, manage
agents, schedule jobs and send chat messages — all programmatically, from external
applications.
