# Análise de Dataset (EDA)

> `analisar_dataset` — estatísticas, distribuições e correlações antes de treinar.

```json
{
  "componente": {},
  "entradas": ["$dataset"]
}
```

Retorna:

- Estatísticas descritivas por coluna (média, desvio, min, max, quartis)
- Distribuição de NaN por coluna
- Matriz de correlação entre features
- Distribuição do target
