# Dataset Analysis (EDA)

> `analisar_dataset` — statistics, distributions and correlations before training.

```json
{ "componente": {}, "entradas": ["$dataset"] }
```

Returns:

- Descriptive statistics per column (mean, std, min, max, quartiles)
- NaN distribution per column
- Correlation matrix between features
- Target distribution
